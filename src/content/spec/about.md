# 关于我 / About Me

你好，我是 **Otaku**。

白天写代码，晚上追番，偶尔半夜爬起来折腾服务器。这个博客叫「次元代码终端 / Terminal 0x7F」——名字里两样东西，差不多就是我全部的爱好了。

- **框架**：[Astro](https://astro.build/)，纯静态，没有数据库，没有服务器
- **主题**：[Firefly](https://github.com/CuteLeaf/Firefly)（基于 [Fuwari](https://github.com/saicaca/fuwari) 二次开发）
- **源码**：[github.com/QUITERO/Firefly789](https://github.com/QUITERO/Firefly789)
- **托管**：GitHub 存源码，推送即自动构建部署

写博客的原因很朴素：记性不好。踩过的坑、想明白的事，不写下来过两个月就忘干净了。所以这里大部分内容是「写给未来的自己看」的技术笔记，剩下的就是随手记的日常。
